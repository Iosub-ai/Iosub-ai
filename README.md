# Iosu Buenetxea

Founder of the **[Berpiztu](https://github.com/Berpiztu)** initiative and
independent AI alignment researcher. I believe AI should work from values and
character, not from constraints alone, and I build both the research and the
tools around it.

## What I have built

- **[Virtus](https://github.com/Berpiztu/virtus)**: AI alignment research,
  values instead of constraints. Paper:
  [doi.org/10.5281/zenodo.21127304](https://doi.org/10.5281/zenodo.21127304).
- **[Virtus Labs](https://github.com/Berpiztu/virtus/tree/main/labs)**:
  reproducible experiments and benchmarks that test Virtus against real
  models, to produce evidence, not just claims.
- **[WSLC AI Agent](https://github.com/Berpiztu/wslc-ai-agent)**: a local
  agent and MCP server for Microsoft's WSLC containers, with a web dashboard,
  Windows and Android clients, and a skill for AI agents.
- **[KeyPlus](https://github.com/Berpiztu/keyplus)**: the keys a phone's
  keyboard lacks (Esc, Tab, Ctrl, Alt, the arrows…) for a terminal, an SSH
  app or a web editor, as a strip above any keyboard or as Berpiztu AI
  Keyboard, for any Android and for a headset (Galaxy XR).
- **[security-watch](https://github.com/Berpiztu/security-watch)**: every
  library my projects use, checked every day against the known
  vulnerabilities.
